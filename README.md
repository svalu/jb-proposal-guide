# 우아한형제들 제안서 디자인 시스템

최신 가이드: [우형제안서_디자인시스템_v2.2.md](./우형제안서_디자인시스템_v2.2.md)

## 내려받기

- 한 파일만: 위 가이드 링크를 열고 **Download raw file**을 누릅니다.
- 전체 저장소: 상단 **Code → Download ZIP**을 누릅니다.
- 비공개 저장소이므로 `svalu` 계정으로 로그인해야 합니다.

## 사용하기

1. 가이드 MD와 작업할 PPTX를 함께 준비합니다.
2. 작업 요청에 `우형제안서_디자인시스템_v2.2.md를 먼저 읽고, 원본 PPTX의 텍스트와 장 순서를 유지하면서 디자인해줘`라고 명시합니다.
3. 타이틀·거버닝은 §2–3, 501.1pt 바닥선과 카드 간격은 §14를 확인합니다.
4. 미리보기와 최종 PPT에서 글자 넘침, 카드 바닥선, 줄간격을 확인합니다.

이 문서는 **우아한형제들 제안서 판형과 색상** 기준입니다. JB금융 등 다른 마스터에는 501.1pt 좌표와 민트 색상을 그대로 적용하지 말고, 해당 마스터의 판형과 브랜드 규칙으로 조정해야 합니다.

원본 MD를 그대로 보관합니다. 문서 안 §0의 요청 예시에 적힌 `v2.0.md`는 과거 파일명이며, 현재 사용 파일은 **v2.2**입니다.
