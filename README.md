# JB금융그룹 제안서 디자인 가이드

JB금융그룹 제안서 마스터를 기준으로 정리한 디자인 검수용 가이드입니다.

- [JB금융그룹 디자인 시스템 v1.0](JB금융그룹_디자인시스템_v1.0.md): 판형, 타이틀·거버닝·라벨, 501.1pt 바닥, 색, 카드·표·선, 검수 체크리스트
- [AI 디자인 검수 사용법](JB_AI_디자인검수_사용법.md): PPTX와 MD를 함께 전달할 때의 요청 방법

**다운로드:** GitHub의 `Code → Download ZIP`을 누르거나, 위 MD 파일을 열어 다운로드하세요. 이 저장소는 비공개이므로 접근 권한이 있는 계정으로 로그인해야 합니다.

**주의:** MD는 기준을 요약한 문서입니다. 실제 PowerPoint 화면에서 글자 넘침, 정렬, 이미지 크롭, 가이드선을 반드시 사람이 최종 확인하세요.

우아한형제들 문서는 작성 형식을 참고한 샘플입니다. 이 저장소의 규격은 JB금융그룹 PPTX에서 확인한 값으로 작성했습니다.
