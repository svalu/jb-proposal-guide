AI 검수 순서·요청문: [AI_디자인검수_사용법.md](./AI_디자인검수_사용법.md)

## 내려받기

- 한 파일만: 파일 링크를 열고 **Download raw file**을 누릅니다.
- 전체 저장소: 상단 **Code → Download ZIP**을 누릅니다.
- 비공개 저장소이므로 `svalu` 계정으로 로그인해야 합니다.

원본 규칙은 v2.2 MD에 있습니다. 타이틀·거버닝은 §2–3, 가이드선과 카드 간격의 **501 규칙은 §14**를 보세요. 다른 사람이 AI에게 디자인 교정을 맡길 때는 `AI_디자인검수_사용법.md`의 검수 요청문을 함께 사용하면 됩니다.

이 문서는 **우아한형제들 제안서 판형과 색상** 기준입니다. JB금융 등 다른 마스터에는 501.1pt 좌표와 민트 색상을 그대로 적용하지 말고, 해당 마스터의 판형과 브랜드 규칙으로 조정해야 합니다.
